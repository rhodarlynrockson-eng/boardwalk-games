
# Boardwalk Games

## Project Overview

Boardwalk Games is a responsive website for a board game shop and café.

The website aims to showcase the games, events and activities available, provide useful information to customers, and encourage visits to the physical shop.

This website is being developed as part of the Code Institute Level 5 Full Stack Web Development course.

## Project Type

This is a guided practice project based on learning materials provided by Code Institute.

## Technologies Used

- HTML5 — website structure
- CSS3 — custom styling
- Bootstrap 5.3.3 — responsive layout and components
- Visual Studio Code — code editor
- Git and GitHub — version control
